# Política de Privacidad — Affiliate Automation

**Última actualización: 15 de agosto de 2026**

## 1. Información general

Affiliate Automation es una herramienta personal destinada a la investigación, creación, publicación y análisis de contenido en Pinterest.

## 2. Datos utilizados

Cuando el usuario autoriza el acceso mediante la API oficial de Pinterest, la aplicación puede acceder a los datos necesarios para proporcionar sus funciones, incluyendo información de la cuenta, Pines, tableros y métricas disponibles.

## 3. Uso de los datos

Los datos se utilizan exclusivamente para las funciones autorizadas por el usuario, incluyendo:

- Consultar información de la cuenta.
- Consultar Pines y tableros.
- Crear y programar Pines.
- Analizar resultados.
- Generar informes.
- Optimizar contenido.

## 4. Compartición de datos

Affiliate Automation no vende los datos obtenidos mediante Pinterest ni los comparte con terceros para fines independientes de la aplicación.

## 5. Seguridad

Las credenciales de acceso se mantienen fuera del código fuente y no se muestran intencionalmente en registros, interfaces públicas o respuestas de la aplicación.

## 6. Retirada del acceso

El usuario puede retirar la autorización concedida a la aplicación y eliminar las credenciales utilizadas para acceder a Pinterest.

## 7. Eliminación de datos

Los datos almacenados por la aplicación pueden eliminarse mediante los mecanismos disponibles en la propia aplicación o retirando las credenciales de acceso.

## 8. Contacto

Para consultas relacionadas con Affiliate Automation, el usuario puede utilizar los mecanismos de contacto disponibles en la cuenta del desarrollador.
